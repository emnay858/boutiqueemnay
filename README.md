# Tienda de ropa sencilla

Proyecto estático en HTML + CSS + JavaScript.

## Cómo abrir
1. Descomprime el ZIP.
2. Abre `index.html` en Chrome/Edge.
3. Para pedidos por WhatsApp, edita `js/app.js` y cambia:
   `const phone = "5210000000000";`
   por el número de WhatsApp del negocio.

## Incluye
- Catálogo de productos.
- Filtro por categoría.
- Carrito.
- Cantidades +/−.
- Persistencia del carrito con localStorage.
- Total en MXN.
- Pedido por WhatsApp.
- Diseño responsive para celular y PC.

## Para personalizar
- Productos: `js/app.js`
- Diseño: `css/styles.css`
- Imágenes: carpeta `img`
- Estructura: `index.html`
